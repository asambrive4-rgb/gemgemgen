# GemGemGen 디자인 시스템 가이드 (디자인.md)

이 문서는 GemGemGen 앱의 모든 화면(자동화, 분석 생성, 와일드카드, 설정)이 **일관되고 세련된 소프트 3D 뉴모피즘(Clay & Pebble)** 스타일을 유지하기 위한 디자인 표준 규격서입니다.

UI 컴포넌트를 추가, 수정, 리팩터링할 때는 반드시 이 문서의 기준을 따릅니다.

---

## 1. 디자인 컨셉: 소프트 3D 뉴모피즘 (Clay & Pebble)

평면적(Flat)이고 딱딱한 네모 상자 위주의 레이아웃을 지양하고, **만지고 싶은 조약돌 형태(Pebble Shape)**와 **쫀득한 입체감(Soft 3D / Clay Extrusion)**을 통해 스마트폰 화면에 최적화된 감각적인 조작감을 제공합니다.

### 핵심 조형 원칙
1. **3D 조약돌 카드 (Extruded Card)**: 
   - 20~26dp의 넉넉한 둥근 모서리(Rounded Corner).
   - 상단 백색 하이라이트 + 하단 부드러운 소프트 섀도우를 결합하여 바닥에서 부드럽게 솟아오른 입체감.
2. **인셋 입력 베드 (Inset Field Bed)**:
   - 텍스트 입력창, 에디터 본문, 탭 트랙은 바닥으로 쏙 들어간 음각(Inset) 느낌의 톤온톤 배경 적용.
3. **쫀득한 클레이 버튼 (Clay Pill Button)**:
   - 12~16dp 라운딩의 캡슐 형태, 메인 컬러의 선명한 입체 글로우 그림자 적용.
4. **8dp 간격 리듬**:
   - 화면 외곽 패딩: 16dp
   - 섹션 간격: 12dp
   - 컴포넌트/아이템 간격: 8dp, 4dp

## 3. 화면별 통일 기준

### 1) 메인 탭바 (`MainTabbedScreen.kt`)
- 상단 탭은 음각 인셋 트랙(Inset Track, 24dp 라운딩) 내부에 배치.
- 선택된 탭은 조약돌처럼 볼록하게 올라온 캡슐 칩(Active Pill, Primary 색상 및 백색 글자)으로 표시.

### 2) 자동화 탭 (`AutomationScreen.kt`, `PromptSection.kt`, `AutomationActionBar.kt`)
- **타겟 앱 선택**: Gemini / ChatGPT 알약 칩(높이 30dp, 라운딩 15dp).
- **프롬프트 템플릿**: 외곽 3D 조약돌 카드 + 내부 인셋 텍스트필드 베드.
- **액션 아일랜드**: 3D 조약돌 유틸리티 버튼(높이 36dp, 라운딩 12dp).
- **시작/중지 액션 바**: 큼직하고 쫀득한 메인 액션 버튼(높이 48~52dp)과 스텝퍼.

### 3) 분석 생성 탭 (`AnalysisScreen.kt`)
- **모델 및 프로바이더 선택**: 3D 캡슐 칩으로 통일(높이 28dp, 라운딩 14dp).
- **50:50 분할 창**: 원문 입력창과 마스킹 결과창을 대칭되는 3D 트윈 카드로 배치.
- **하단 고정 바**: TXT 생성 및 생성 버튼을 메인 3D Clay 버튼 스타일로 일원화.

### 4) 와일드카드 탭 (`WildcardManagerScreen.kt`)
- **레거시 하드코딩 색상 배제**: 과거 LightMemo의 하드코딩 파스텔 컬러(`MemoPrimary`, `MemoTabSelected` 등)를 완전히 제거하고 공통 `AppColors` 토큰 사용.
- **파일 탭 스트립**: 3D 조약돌 칩 가로 스크롤.
- **일체형 에디터 카드**: 상단 부드러운 헤더 띠와 하단 인셋 텍스트 에디터 일체화.
- **언어 한글화 표준**: "Storage folder" ➔ "와일드카드 저장소", "Select Folder" ➔ "폴더 변경" 등 한글 표준 적용.

### 5) 설정 다이얼로그 (`StatusSettingsDialog.kt`)
- 다이얼로그 상단에 **[디자인 테마 팔레트]** 섹션 배치.
- 팔레트 1(코랄), 팔레트 2(세이지, 기본값), 팔레트 3(인디고) 선택 라디오 칩 제공.
