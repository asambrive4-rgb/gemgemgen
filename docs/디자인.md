# GemGemGen 디자인 시스템 가이드 (디자인.md)

이 문서는 GemGemGen 앱의 모든 화면(자동화, 분석 생성, 와일드카드, 설정)이 **일관되고 세련된 토스 스타일(Toss-Like Clean & Borderless)**을 유지하기 위한 디자인 표준 규격서입니다.

UI 컴포넌트를 추가, 수정, 리팩터링할 때는 반드시 이 문서의 기준을 따릅니다.

---

## 1. 디자인 컨셉: 토스 스타일 무테두리 고대비 카드 (Clean & Borderless)

복잡한 외곽선(Border)과 과도한 입체 그림자, 긴 설명 문구를 지양하고, **배경(Canvas)과 순백색 카드(Card)의 뚜렷한 명도 대비**, **부드러운 톤온톤 인셋 면(Inset Surface)**, **핵심 키워드/숫자 중심의 타이포그래피**로 단계별 분리감과 직관적인 조작감을 제공합니다.

### 핵심 조형 원칙
1. **무테두리 클린 카드 (`NeuCard`)**:
   - 20~22dp의 넉넉한 둥근 모서리(`RoundedCornerShape`).
   - 외곽선(`border`) 0dp. 차분한 배경(`canvas`) 위에 순백색 카드(`#FFFFFF`)와 은은한 확산형 그림자(`elevation = 2.dp`)만으로 섹션과 단계를 또렷하게 분리합니다.
2. **무테두리 인셋 베드 (`NeuInsetBed` & `appTextFieldColors`)**:
   - 텍스트 입력창, 에디터 본문, 비활성 칩, 상단 탭 트랙은 외곽선을 그리지 않고 부드러운 회색/톤온톤 면(`insetBed`)으로만 구분합니다.
   - 텍스트필드는 포커스되었을 때만 얇은 포인트 컬러 테두리로 활성 상태를 안내합니다.
3. **솔리드 캡슐 버튼 & 알약 칩 (`NeuButton`, `NeuPillChip`)**:
   - 12~14dp 라운딩의 무테두리 솔리드/소프트 버튼.
   - 보조 액션은 `insetBed` 또는 `primary.copy(alpha = 0.12f)` 소프트 배경을, 메인 액션(CTA)은 선명한 `primary` 솔리드 배경을 사용합니다.
4. **단계별 카드 간격 리듬**:
   - 화면 외곽 패딩: 12~16dp
   - 단계별 카드 간격: 12dp
   - 카드 내부 패딩: 16dp (컴포넌트 간격 8~12dp)

## 2. 4가지 선택형 색상 팔레트 (기본값: 팔레트 0 토스 시그니처)

설정(`StatusSettingsDialog`)에서 사용자가 0, 1, 2, 3번 팔레트를 자유롭게 선택할 수 있으며, **기본값은 팔레트 0(토스 시그니처)**입니다. 모든 라이트 팔레트는 카드(`card`)를 순백색(`#FFFFFF`)으로 통일하여 배경(`canvas`)과의 단계별 분리감을 극대화합니다.

| 구성 요소 | 💙 팔레트 0 (토스 시그니처) [기본값] | 🍑 팔레트 1 (웜 코랄 크림) | 🌿 팔레트 2 (노르딕 세이지) | ⚡ 팔레트 3 (퓨어 인디고) |
| :--- | :--- | :--- | :--- | :--- |
| **캔버스 (배경)** | `#E9EDF2` (선명한 쿨 그레이) | `#EAE3DC` (웜 스톤) | `#E2EBE4` (미스트 그린) | `#E4EAF3` (아이스 블루) |
| **클린 카드 (표면)** | `#FFFFFF` (순백) | `#FFFFFF` (순백) | `#FFFFFF` (순백) | `#FFFFFF` (순백) |
| **인셋 베드 (입력창/칩)** | `#F2F5F8` | `#F4EFEA` | `#EDF3EF` | `#F0F4FA` |
| **메인 포인트 (Primary)** | `#3182F6` (토스 블루) | `#E55A34` (테라코타 코랄) | `#15805D` (딥 세이지) | `#4F46E5` (로얄 인디고) |
| **보조 강조 (Accent)** | `#00C471` (에메랄드 그린) | `#FF8A65` | `#2563EB` | `#EC4899` |
| **본문 텍스트** | `#191F28` | `#221C16` | `#14221B` | `#111827` |
| **보조 텍스트** | `#8B95A1` | `#7E7266` | `#64786D` | `#64748B` |

- **다크 모드 3단계 표면 대비 (`crisp_toss`)**:
  - 캔버스(`canvas`): `#0A0A0C` (딥 블랙)
  - 클린 카드(`card`): `#171B22` (다크 슬레이트 카드)
  - 인셋 베드(`insetBed`): `#222731` (카드 내부 입력창·중립 칩)
  - 메인 포인트(`primary`): 각 팔레트의 고유 포인트 컬러 유지 (무테두리 솔리드/소프트 틴트 위계 보장)

## 3. 화면별 통일 기준

### 1) 메인 탭바 (`MainTabbedScreen.kt`)
- 상단 탭은 무테두리 인셋 트랙(`insetBed`, 16dp 라운딩) 내부에 배치.
- 선택된 탭은 순백색(다크모드는 다크 카드) 화이트 알약(`card`, 12dp 라운딩)으로 깔끔하게 부각.

### 2) 분석 생성 탭 (`AnalysisScreen.kt`) — 토스식 단계별 카드 구조
- **상단 통합 캡슐 헤더 (`unified_pill`)**: 마스킹 모델, 생성 모델 드롭다운 캡슐과 `🔑 키`, `Grok N%` 상태 배지를 단 1줄의 카드에 압축 배치.
- **STEP 1 카드 (원문 & 분석 타겟)**:
  - `1`번 원형 배지 + `[자동화에서 가져오기]` 미니 배지 버튼.
  - 100% 풀폭 무테두리 인셋 원문 입력창.
  - 원문 바로 아래에 **인라인 마스킹 타겟 하이라이트 배너 (`inline_banner`)** 배치.
  - 한눈에 모든 카테고리를 보고 고를 수 있는 **2줄 그리드 칩 (`grid_chips`)** 내장.
- **STEP 2 카드 (변주 방향 & 요청사항)**:
  - `2`번 원형 배지 + 선택 개수 표시.
  - 선택 시 체크(`✓`)와 소프트 컬러가 채워지는 무테두리 방향 칩.
  - 불필요한 제목과 글자수 카운터를 제거한 1줄 인셋 힌트 입력창.
- **STEP 3 카드 (추천 후보 / TXT 결과)**:
  - 긴 설명 문구를 제거하고 직관적인 번호 배지(`1`~`6`), 본문, 우측 `[복사]` 미니 버튼만 배치.
  - TXT 모드에서는 결과 프리뷰 하단에 파일명 입력창과 `[파일 저장]` 버튼을 카드 내부에 일체형으로 배치.
- **하단 플로팅 액션 독 (`floating_dock`)**:
  - 오직 실행에만 집중하는 1줄 플로팅 바: `[🔄 초기화]` + `[개수 N | TXT 생성]` 일체형 분할 버튼 + `[✨ 카드 생성 (6)]` 솔리드 버튼.

### 3) 자동화 탭 & 와일드카드 탭 (`AutomationScreen.kt`, `WildcardScreen.kt`)
- **자동화 탭 2단 분리형 카드 (`two_step_cards`)**:
  - **카드 1 (프롬프트 입력 카드)**: 무테두리 인셋 앱 선택 칩, 모드 토글, 헤더 아이콘 알약 버튼, 멀티라인 인셋 입력창을 하나의 클린 카드(`NeuCard`)로 통합.
  - **카드 2 (빠른 도구 모음 카드)**: 하단 보조 도구 영역을 별도의 클린 카드로 분리.
- **토스 3단계 플랫 칩 위계 (`toss_3tier_flat`)**:
  - **Tier 1 (Primary Solid)**: 하단 플로팅 독의 `[▶ 시작]`, `[저장]` 등 최우선 실행 CTA.
  - **Tier 2 (Primary Soft Tint)**: `primary.copy(alpha = 0.14f)` 배경 + `primary` 텍스트 (`변주`, `복사`, `가져오기`, 활성 상태의 `문단 편집`/`정리 예약됨`, 추천 칩).
  - **Tier 3 (Neutral Gray Chip)**: `insetBed` 배경 + `textPrimary`/`textSecondary` 텍스트 (`앱 종료`, `리셋`, `메모리 정리`, 히스토리 화살표, `상단 삽입`, `하단 삽입`).
- **하단 플로팅 통합 독 (`toss_floating_dock`)**:
  - 무테두리 클린 카드 내부에 `[▶ 시작]` 솔리드 버튼, 무테두리 인셋 트랙 내부의 `card` 솔리드 `−`/`+` 스테퍼, 상태 도트 및 소프트 진행 배지를 배치.

## 4. UI/UX 품질 및 접근성 체크리스트
- [ ] 텍스트와 배경의 명도 대비 4.5:1 이상 유지 (WCAG AA 준수).
- [ ] 불필요한 안내용 줄글을 배제하고 짧은 배지와 아이콘으로 상태 전달.
- [ ] 모든 대화형 버튼의 최소 터치 영역 확보 및 명확한 선택 상태 피드백 제공.
