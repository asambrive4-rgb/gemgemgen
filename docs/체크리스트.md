# 자동화 탭 · 메인 화면 UX 개선 체크리스트

이 문서는 gemgemgen의 **메인 화면(탭바)**과 **자동화 탭**을 코드로 검토해 나온 UX 아쉬운 점을 정리한 체크리스트입니다. 각 항목에 근거(코드 위치)와 텍스트 디자인 예시를 함께 적었습니다.

> 💡 **규칙**: 해결 완료된 항목은 체크박스를 체크(`- [x]`)하고, 항목명 및 본문 내용에 취소선(`~~...~~`)을 긋습니다.

> 📝 **검토 범위**: 코드 기반 정적 검토입니다(실행 화면은 미확인). 설정·상용구·계정 사용량·변주/지시문 다이얼로그 내부는 검토하지 않았습니다. 기준 문서는 [디자인.md](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/docs/디자인.md)입니다.

### 2. 시작 바 하단 고정
- **관련 파일**: [AutomationScreen.kt](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/app/src/main/java/com/example/gemgemgen/automation/ui/AutomationScreen.kt)
- **근거**:
  - `AutomationBottomBar`가 스크롤 본문 `Column` 안에 있음(L66-L102). 화면이 작으면 아래로 스크롤해야 시작/중지가 보입니다.

  ```text

  │  사용량 요약 / 모드      │
  │         ↕                │
  ├──────────────────────────┤ ← 항상 보임 (고정)
  │ [▶ 시작]  [− 3 ＋]  ● 대기│
  └──────────────────────────┘
  ```
