# GemGemGen 앱 전체 UI 디자인 시스템(토스 스타일) 불일치 전수조사 체크리스트

이 문서는 GemGemGen 앱의 모든 화면·컴포넌트·다이얼로그를 전수조사하여, 마스터 디자인 규격서([`design-system/gemgemgen/MASTER.md`](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/design-system/gemgemgen/MASTER.md)) 및 디자인 가이드([`docs/디자인.md`](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/docs/디자인.md))에 정의된 **토스 스타일 무테두리 고대비 카드 (Toss-Like Clean & Borderless)** 표준과의 불일치 요소를 한눈에 파악하고 단계별로 일원화할 수 있도록 정리한 체크리스트입니다.

> 🌟 **표준 레퍼런스 화면**: 현재 앱의 **'자동화(Automation) 탭'**([`AutomationScreen.kt`](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/app/src/main/java/com/example/gemgemgen/automation/ui/AutomationScreen.kt))이 앱 전체 화면이 지향하는 **최종 표준 레퍼런스 모델**입니다. 분석 생성, 와일드카드, 다중 계정 사용량, 설정 다이얼로그 등 다른 모든 화면은 자동화 화면의 조형 비율(2단 분리형 클린 카드, 토스 3단계 플랫 칩 위계, 하단 플로팅 독)을 1:1 기준으로 삼아 일원화합니다.

> 💡 **규칙**: 해결 완료된 항목은 체크박스를 체크(`- [x]`)하고, 항목명 및 본문 내용에 취소선(`~~...~~`)을 긋습니다.

### 1. 설정 다이얼로그(`StatusSettingsDialog.kt`) M3 ColorScheme 20곳 하드코딩 이탈
- **관련 파일**:
  - 설정 다이얼로그: [`StatusSettingsDialog.kt` (L72-L590)](file:///c:/Users/joajo/AndroidStudioProjects/gemgemgen/app/src/main/java/com/example/gemgemgen/automation/ui/StatusSettingsDialog.kt#L72-L590)
- **어떤 문제인가요?**:
  - 공통 다이얼로그 프레임인 `NeuModalDialogFrame`이나 `NeuConfigDialogContent`를 사용하지 않고 날(Raw) `Column`과 수동 닫기 버튼으로 구성되었습니다.
  - 설정 그룹 컨테이너가 `NeuCard`나 `NeuInsetBed` 대신 `Surface(color = MaterialTheme.colorScheme.surfaceVariant.copy(0.38f))`로 하드코딩되었습니다.
  - `MaterialTheme.colorScheme.onSurface`, `onSurfaceVariant`, `surfaceVariant`, `outlineVariant`, `primaryContainer`, `errorContainer` 등을 20군데 이상 직접 참조하고 있습니다.
  - 버튼 역시 M3 순정 `Button`, `OutlinedButton`, `TextButton`을 직접 사용하고 있습니다.
- **실제 영향**:
  - 사용자가 설정 창에서 4종 토스 테마 팔레트(토스 시그니처, 웜 코랄 크림, 노르딕 세이지, 퓨어 인디고)를 변경해도, 설정 다이얼로그 내부의 카드와 텍스트는 테마 팔레트에 반응하지 않고 혼자 붕 뜨는 이질감이 발생합니다.
- **개선 방안**:
  - `NeuModalDialogFrame` 및 `NeuConfigDialogContent(useNeuButtons = true)`로 감싸고, 모든 M3 ColorScheme 호출을 `AppTheme.colors` 토큰으로 전면 교체하며, 버튼을 무테두리 `NeuButton`으로 일원화합니다.
