# 외부 ZIP 코드 안전 분석 및 동기화 스킬 (import-clean-zip)

외부 AI 에이전트(Claude, Cursor, ChatGPT 등)가 작업을 마치고 전달한 ZIP 파일이나 수정된 아카이브를 프로젝트에 반영할 때, **무단 덮어쓰기를 원천 방지하고 변경 내역을 먼저 분석하여 사용자 승인 후 안전하게 동기화**하는 표준 워크플로우 스킬입니다.

---

## ⚠️ 절대 생략 불가 필수 원칙 (Non-Negotiable Rules)

1. **즉시 적용 절대 금지 (Never Apply Directly)**
   - 첨부된 ZIP 파일을 바로 프로젝트에 덮어쓰는 행위는 엄격히 금지됩니다.
   - 반드시 **1단계 분석(Diff Analysis)**을 먼저 수행하고, 무엇이 달라졌는지 사용자에게 보고한 뒤 확인을 받아야 합니다.
2. **미커밋 작업 사전 확인 (Uncommitted Changes Check)**
   - 로컬 프로젝트에 커밋되지 않은 작업(`git status`)이 감지되면, 진행 전에 **반드시 사용자에게 현재 상태를 알리고 계속 진행할지 확인**해야 합니다.
3. **옵션 A 동기화 (추가 및 수정만 반영)**
   - ZIP에 있는 신규 파일과 수정된 파일만 안전하게 복사하며, 로컬에만 있는 기존 파일은 절대 임의로 삭제하지 않습니다.
4. **로컬 고유 환경 파일 원천 보호 (Protected Files)**
   - `local.properties` (로컬 Android SDK 경로 및 API 키)
   - `.git/` (버전 관리 히스토리)
   - `.gradle/`, `build/`, `.idea/`, `.kotlin/` (로컬 캐시 및 IDE 설정)
   - 위 파일들은 ZIP 파일 내부에 포함되어 있더라도 **절대 덮어쓰지 않고 로컬 상태를 유지**합니다.

---

## 0. 사용 시점 및 트리거 조건

- **사용 시점**:
  - 사용자가 대화창에 ZIP 파일을 드래그 앤 드롭으로 첨부했을 때
  - "이 zip 파일 프로젝트에 반영해줘", "수정된 zip 코드 적용해줘" 등의 요청 시
  - `$import-clean-zip` 명령 호출 시

---

## 1. 단계별 실행 절차 (Runbook)

### [1단계] ZIP 차이점 분석 및 사용자 브리핑 (적용 금지, 분석만 수행)

첨부된 ZIP 파일 경로를 인자로 전달하여 분석 스크립트를 실행합니다.

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".agents\skills\import-clean-zip\scripts\analyze_diff_zip.ps1" -ZipPath "<첨부된_ZIP_경로>"
```

- 스크립트 동작:
  1. 현재 프로젝트의 `git status` 점검 (미커밋 변경사항 확인)
  2. 시스템 임시 폴더에 안전하게 압축 해제
  3. ZIP 내부 구조 자동 판별 (Flat 구조 또는 최상위 폴더 감쌈 여부 자동 정규화)
  4. 로컬 프로젝트 파일과 1:1 비교 (신규 파일, 수정 파일, 동일 파일, 보호된 파일 분류)
  5. 승인용 메타데이터(`import_metadata.json`) 임시 생성

### [2단계] 사용자에게 변경점 상세 보고 및 확인 요청

에이전트는 스크립트 분석 결과를 바탕으로 다음 내용을 사용자에게 구조화하여 보고합니다:
- **로컬 미커밋 작업 여부**: 미커밋 파일이 있을 경우 안내 및 주의 환기
- **신규 추가된 파일 목록**: 새로 생긴 클래스, 함수, 리소스
- **수정된 파일 목록 및 변경 내용**: 어떤 로직/기능이 수정되었는지 요약
- **사용자 승인 요청**: *"위 변경 사항을 프로젝트에 적용하시겠습니까?"* 질의

### [3단계] 사용자 승인 후 실제 코드 동기화 (Apply)

사용자가 변경 내역을 확인하고 명시적으로 승인(예: "적용해줘", "진행해")한 경우에만 2단계 적용 스크립트를 실행합니다.

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".agents\skills\import-clean-zip\scripts\apply_clean_zip.ps1" -MetadataPath "<1단계에서_출력된_import_metadata.json_경로>"
```

- 스크립트 동작:
  1. 보호 파일(`local.properties` 등)을 제외하고 신규/수정 파일만 로컬에 복사
  2. 사용 완료된 임시 스테이징 폴더 완전 자동 삭제
  3. 최종 적용 완료 통계 출력

## 2. 사후 검증 체크리스트

- [ ] 미커밋 작업이 있을 때 사용자에게 사전에 확인을 구했는가?
- [ ] ZIP 내부의 변경점을 먼저 분석하여 사용자에게 상세히 보고했는가?
- [ ] 사용자의 명시적인 승인 없이 코드를 덮어쓰지 않았는가?
- [ ] `local.properties` 등 로컬 필수 파일이 안전하게 보존되었는가?
- [ ] 적용 완료 후 임시 폴더가 정상 삭제되었는가?
